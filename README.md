# 📚 Class Task Management System

A full-stack web application built to help students manage and track their daily academic tasks, assignments, and deadlines. 

## 🚀 Features
* **Create, Read, Update, Delete (CRUD):** Fully functional task management.
* **Smart Search & Filtering:** Instantly find tasks by title or filter by status (Pending, In Progress, Completed).
* **Persistent Storage:** Custom file-based database system using Node.js fs module to prevent data loss.
* **Modern UI/UX:** Clean, responsive interface with intuitive color-coded status indicators and polite error handling.

## 💻 Tech Stack
* **Frontend:** React.js, Vite, HTML5, CSS3
* **Backend:** Node.js, Express.js
* **Database:** JSON File System Storage
* **API:** RESTful architecture connecting React to Express

## 🛠️ How to Run Locally

1. Start the Backend:
Open a terminal, type "cd backend" and press Enter.
Type "node server.js" and press Enter.

2. Start the Frontend:
Open a new terminal, type "cd frontend" and press Enter.
Type "npm run dev" and press Enter.

3. Open in Browser:
Navigate to the local link provided by Vite (usually http://localhost:5173/).
